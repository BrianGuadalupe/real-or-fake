# Real or Fake?

Juego web de 14 rondas para adivinar si un vídeo de calzado es real o está generado con inteligencia artificial. La interfaz está en inglés.

## Catálogo actual

`public/clips.json` contiene 14 vídeos activos y cada partida utiliza todos, en orden aleatorio:

- 7 vídeos generados con IA suministrados por el propietario. Sus originales están en Google Drive.
- 4 vídeos reales procedentes de Pexels, bajo la Pexels License.
- 3 vídeos reales procedentes de Wikimedia Commons, con su licencia indicada en el catálogo.

Los 14 archivos que reproduce el juego están en `public/videos`. Todos son MP4 H.264 con `faststart` y usan nombres neutros para no revelar la respuesta.

## Por qué el juego no reproduce directamente desde Drive

Los enlaces de Google Drive son válidos y públicos, pero el endpoint de descarga no es un servicio de streaming: puede bloquear una petición realizada desde otra web, tarda varios segundos en responder y no ofrece una caché pública estable. Eso provocaba vídeos lentos, pantallas de error y rondas que desaparecían.

Drive se conserva como archivo original y como enlace de procedencia. Durante la partida, el navegador descarga las copias locales desde el mismo dominio que la web. Así la reproducción no depende de Drive, Pexels ni Wikimedia y después podrá publicarse como contenido estático en GitHub Pages.

## Añadir o sustituir vídeos

1. Comprueba la autoría, licencia o permiso del vídeo y conserva el original.
2. Convierte el archivo a MP4 con H.264 o a WebM con VP9. Para una carga ágil, intenta que pese menos de 8 MB y, en MP4, activa `faststart`.
3. Copia el archivo a `public/videos` con un nombre neutro, por ejemplo `clip-015.mp4`.
4. Añade su ficha a `public/clips.json` usando una ruta relativa.
5. Ajusta `settings.roundCount` si quieres cambiar el número de rondas.

Ejemplo:

```json
{
  "id": "clip-015",
  "enabled": true,
  "truth": "ai",
  "media": {
    "provider": "direct",
    "url": "videos/clip-015.mp4"
  },
  "provenance": {
    "label": "Generated by AI",
    "detail": "Original generation; source file retained.",
    "sourceName": "Original source",
    "sourceUrl": "https://drive.google.com/file/d/ID/view",
    "model": "Provider and model version",
    "license": "Original generation",
    "date": "2026-09"
  }
}
```

También puedes partir de `public/clips.example.json`.

## Reglas del catálogo

- `truth` acepta `camera` para Real y `ai` para Fake.
- No incluyas `real`, `fake`, `ai` ni el nombre del modelo en los nombres de archivo.
- Conserva fuera de la web el original, su hash, el prompt o consentimiento y una copia de la licencia.
- Excluye los vídeos parcialmente editados con IA o de procedencia dudosa del juego binario.
- Las respuestas de `clips.json` son visibles para quien inspeccione el código. Es un juego casual, no una competición con premios.
- No reutilices campañas oficiales de Camper o NNormal sin una licencia compatible o permiso expreso.

## Desarrollo

```bash
npm run dev
```

```bash
npm run build
```
