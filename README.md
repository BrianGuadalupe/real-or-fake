# Real or Fake?

Juego web de diez rondas para adivinar si un vídeo de calzado fue grabado con cámara o generado con inteligencia artificial. La interfaz está en inglés y el resultado de cada ronda muestra la procedencia documentada.

## Catálogo actual

`public/clips.json` contiene 14 vídeos activos:

- 7 clips generados con IA suministrados por el propietario y alojados en Google Drive.
- 3 vídeos reales de fabricación artesanal procedentes de Wikimedia Commons, con licencia CC BY-SA.
- 4 vídeos reales de talleres, pasos, cordones y zapatillas procedentes de Pexels, bajo CC0 o la Pexels License.

Cada partida escoge 10 clips al azar, con 5 vídeos reales y 5 generados con IA siempre que ambas categorías tengan suficiente material.

No se han copiado campañas oficiales de Camper o NNormal: si un vídeo de marca no publica una licencia reutilizable, necesitas permiso expreso antes de incorporarlo.

## Añadir vídeos desde Google Drive

1. Sube cada MP4 a una carpeta de Drive dedicada al juego.
2. Usa nombres neutros como `clip-001.mp4`; no pongas el modelo, `real`, `fake` o `ai` en el nombre.
3. En cada archivo, abre **Compartir → Acceso general → Cualquier persona con el enlace → Lector**.
4. Copia el enlace de compartir.
5. Añade un objeto a `public/clips.json`.

Ejemplo de vídeo grabado:

```json
{
  "id": "clip-001",
  "enabled": true,
  "truth": "camera",
  "media": {
    "provider": "drive",
    "shareUrl": "https://drive.google.com/file/d/ID_DEL_ARCHIVO/view?usp=sharing"
  },
  "provenance": {
    "label": "Shot on camera",
    "detail": "Recorded by Name in Madrid. Original file retained.",
    "sourceName": "Creator or source",
    "sourceUrl": "https://...",
    "license": "Owned / Pexels / CC BY...",
    "date": "2026-09"
  }
}
```

Ejemplo generado con IA:

```json
{
  "id": "clip-002",
  "enabled": true,
  "truth": "ai",
  "media": {
    "provider": "drive",
    "shareUrl": "https://drive.google.com/file/d/ID_DEL_ARCHIVO/view?usp=sharing"
  },
  "provenance": {
    "label": "Generated by AI",
    "detail": "Original generation; prompt and source file retained.",
    "model": "Provider and model version",
    "license": "Original generation",
    "date": "2026-09"
  }
}
```

También puedes partir de `public/clips.example.json`.

### Cómo se reproducen los archivos de Drive

La aplicación extrae el identificador del enlace y carga el MP4 mediante el endpoint público de contenido de Drive. Así usa el reproductor nativo del navegador y no enseña el nombre del archivo durante la ronda.

Drive sí conserva el nombre en las cabeceras de descarga, por lo que un usuario técnico podría verlo. Renombra siempre los archivos con nombres neutrales antes de publicar. El identificador y el enlace no cambian al renombrarlos.

Google Drive no es una CDN: puede imponer límites de tráfico o cambiar el comportamiento de descarga. Para una versión pública con muchas visitas, migra los vídeos a R2, S3, Cloudinary u otro almacenamiento preparado para streaming y usa una fuente directa:

```json
"media": {
  "provider": "direct",
  "url": "https://cdn.example.com/clip-002.mp4",
  "poster": "https://cdn.example.com/clip-002.jpg"
}
```

## Reglas del catálogo

- `truth` solo acepta `camera` o `ai`.
- Usa identificadores y nombres de archivo que no revelen la respuesta.
- Conserva fuera de la web el original, su hash, el prompt o consentimiento y una copia de la licencia.
- Excluye del juego binario los vídeos parcialmente editados con IA o de procedencia dudosa.
- Las respuestas de `clips.json` son visibles para quien inspeccione el código. Es un juego casual, no una competición con premios.
